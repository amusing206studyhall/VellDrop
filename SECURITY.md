# Security policy

This beta has not received an independent cryptographic or application audit.
Report vulnerabilities privately using the operator contact configured on /contact.
Before public launch a real monitored security contact must be supplied.
Never include real passwords, private keys or confidential documents in a report.

See docs/THREAT_MODEL.md and VALIDATION.md. Dependency updates and a clean npm audit
are not proof of application security. Live subscriptions and online shares are
feature-gated pending deployment acceptance.
